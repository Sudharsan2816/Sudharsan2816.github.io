  2. Personal buildRAG

    Market Research Copilot

    Fixed-size chunks beat semantic chunking on 32 labelled questions: complete-hit@3 of 100% vs 90.6%.

    FAISS pulls 20 candidates, NVIDIA NIM reranks to 6, and a relevance threshold makes it decline questions the documents don't cover. A live test caught 3 failures; after fixes the retest passed 10 of 10.

    • FastAPI
    • FAISS
    • NVIDIA NIM
    • React
    • Docker

    Next: the benchmark corpus is 6 pages; growing the labelled set before generalising.

    Read the case studyCode
  3. Personal buildAgents

    AI Code Review Agent

    Every review runs as a LangGraph state machine whose approval gate is a real branch: post to the PR, or hold for a human.

    Webhooks without a valid HMAC-SHA256 signature are rejected. Findings that don't quote a changed line are dropped, and the verdict is computed in code. Each commit is reviewed once, however often GitHub delivers it. 22 tests in CI.

    • LangGraph
    • FastAPI
    • GitHub API
    • Claude API
    • MongoDB

    Next: reviews run as in-process background tasks, so a server restart mid-review loses the work.

    Read the case studyCode
  4. Personal buildSecure RAG

    Permission-Aware RAG

    Every retriever filters by the user's role, so restricted documents never reach the model. 7 of 7 allow/deny cases pass.

    JWT login across six roles, retrieval over PDFs, CSV incident reports, JSON logs and SQLite records, redaction of sensitive values, and an audit log of every query. 29 tests in CI.

    • FastAPI
    • FAISS
    • JWT
    • SQLite
    • Docker

    Next: prompt-injection screening is pattern-based; a classifier would catch paraphrased attacks.
